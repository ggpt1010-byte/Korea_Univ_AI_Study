# AI개발모임

모임원이 만든 AI 프로젝트를 올리고 서로 써보는 사이트입니다. 빌드 과정이 없는 정적 사이트라서 GitHub Pages에 그대로 올라갑니다.

## 구성

- `index.html` 결과물 목록, `project.html` 결과물 상세, `submit.html` 결과물 등록, `privacy.html` 개인정보 안내, `me.html` 내 정보(로그인한 계정으로 올린 결과물)
- `groups.html` 그룹 들어가기(방 목록 #1부터, 방 만들기), `group.html` 방 화면(제목과 설명, 비공개 결과물, 공개 결과물, 검증)
- `assets/manager.js` 예상 가치(평가 금액, 개선 시 예상 금액)와 매니저 기능, `estimate.html`은 예전 주소를 `submit.html`로 넘기는 페이지
- `assets/config.js` 구글 폼, 구글 시트, 구글 로그인, 피드백 설정을 모아 둔 곳
- `data/projects.json` 직접 넣어 둔 결과물 (지금은 예시)
- `data/submissions.json` 구글 시트에서 받아 둔 등록 내용 사본 (자동으로 갱신)
- `shots/` 체험 링크의 첫 화면 이미지 (자동으로 갱신)
- `scripts/sync.mjs` 구글 시트의 등록 내용을 받아 오는 스크립트
- `scripts/capture.mjs` 첫 화면을 찍는 스크립트

## 등록과 피드백이 움직이는 방식

1. 모임원이 `submit.html`에서 등록하면 내용이 구글 폼으로 가고, 연결된 구글 시트에 한 줄씩 쌓입니다.
2. 사이트는 열릴 때마다 그 시트(웹에 게시한 CSV)를 읽어 목록에 보여 줍니다. 그래서 등록하면 몇 분 안에 나타납니다.
3. GitHub Actions가 20분마다 시트를 확인해서 새 결과물의 체험 링크 첫 화면을 찍어 `shots/`에 넣습니다.
4. 피드백은 utterances로 받습니다. GitHub 계정으로 로그인해서 남기고, 글은 이 저장소의 Issues에 쌓입니다.

오른쪽 위 "로그인"(구글 로그인, `assets/account.js`)은 편의 기능입니다. 로그인하면 "만든 사람" 칸에 이름이 들어가고, 등록할 때 구글 계정 번호를 SHA-256으로 바꾼 값(`g` + 16자리)이 시트의 "계정 번호" 열에 함께 저장됩니다. `me.html`은 이 값이 같은 결과물을 모아 보여 줍니다. 서버에서 다시 확인하지 않으므로 본인 확인은 아니며, 이메일 주소는 쓰지 않습니다. 로그인 상태는 브라우저(localStorage)에 30일 동안만 남습니다.

## 비밀번호 그룹

서버가 없어서 **진짜 보안 기능은 아닙니다.** 가벼운 잠금 장치로만 씁니다.

- 그룹 기록은 결과물 폼과 다른 "그룹 폼"에 쌓입니다. 질문(모두 단답형): `기록 종류`, `그룹 번호`, `그룹 이름`, `그룹 소개`, `비밀번호 값`, `대상 결과물`, `누른 사람`, `평가 금액`, `개선 시 예상 금액`, `평가 메모`. 응답 시트를 웹에 CSV로 게시하고 `config.js`의 `groupSheetCsvUrl`, `groupFormAction`, `groupFormFields`를 채우면 그룹 기능이 열립니다.
- 결과물 폼에는 `그룹 번호`, `공개 범위`(단답형), `사진 주소`(장문형, 한 줄에 하나, 최대 5개)를 더하고 `formFields.group`, `formFields.visibility`, `formFields.images`를 채웁니다.
- 방은 구글 로그인한 사람만 만들 수 있고, 만든 사람의 계정 값이 `누른 사람` 칸에 남아 그 방의 방장이 됩니다. `featuredGroup`에 적은 방이 목록 맨 위(#1)에 옵니다.
- 그룹 번호는 그룹 이름으로 정해지고(`k` + 8자리), 같은 이름은 먼저 만든 그룹만 인정합니다.
- 비밀번호는 그룹 번호를 소금으로 한 PBKDF2-SHA256(15만 번) 값만 시트에 남습니다. 시트가 공개라서 짧은 비밀번호는 시간을 들이면 알아낼 수 있습니다.
- 비공개 결과물은 목록에서 빠지고 그룹 멤버에게만 상세 화면을 보여 줍니다. 하지만 공개 시트와 `data/submissions.json`에는 그대로 남습니다.
- 검증은 그룹, 결과물, 누른 사람마다 마지막 기록만 셉니다. `verifyGoal`(기본 3)명이 모이면 "검증됨"이 붙습니다. 누른 사람은 구글 로그인 계정 값이나 브라우저의 무작위 값이라서 여러 번 누르는 것을 완전히 막지는 못합니다.

## 예상 가치와 매니저

- 올라온 결과물마다 "예상 가치"가 붙습니다. 매니저가 달기 전에는 "요청 중", AI 분석을 수락하면 "분석 중"(30분이 지나면 다시 "요청 중"), 단 뒤에는 평가 금액과 개선 시 예상 금액이 보입니다.
- 매니저는 구글 로그인 계정 값으로 정합니다. `config.js`의 `managers`에 적은 계정은 사이트 매니저(모든 결과물), 방을 만든 사람은 그 방의 방장(그 방 결과물)입니다. 계정 값은 각자 `me.html` 아래쪽에서 볼 수 있습니다.
- 매니저는 `me.html`에서 "매니저 모드"를 켜고 끕니다(브라우저에만 저장). 켜면 상세 화면에 금액 직접 달기와 "AI 분석 수락하기"가 보입니다.
- AI 분석은 **매니저 자신의 Anthropic API 키**로 브라우저에서 Claude(`claude-opus-5-5`)를 바로 부릅니다(`anthropic-dangerous-direct-browser-access` 헤더). 운영자의 키는 사이트에 넣지 않습니다. 구조화된 출력(JSON 스키마)으로 받고, 거절되면 서버가 다른 모델로 다시 시도하도록 `fallbacks: "default"`를 켜 두었습니다. AI가 채운 값을 매니저가 확인한 뒤 "이 금액으로 달기"를 눌러야 기록됩니다.
- 기록은 그룹 폼으로 가고(`분석 시작`, `분석 취소`, `가치 평가`), 화면은 매니저 계정 값으로 남은 기록만 셉니다. 폼이 공개라서 남의 계정 값을 적은 가짜 기록을 완전히 막지는 못합니다.

## 올라온 결과물 숨기기

구글 시트의 맨 오른쪽에 `숨김`이라는 열을 만들고, 숨기고 싶은 줄의 그 칸에 아무 글자나 적으면 사이트에서 사라집니다. 줄을 지워도 됩니다.

## 내 컴퓨터에서 보기

```
python3 -m http.server 8000
```

그다음 브라우저에서 http://localhost:8000 을 엽니다.
