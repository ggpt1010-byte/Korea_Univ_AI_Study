결과물을 올릴 때

  • 받는 정보는 프로젝트 이름, 한 줄 소개, 만든 사람, 분류, 체험 링크, 자세한 설명이에요.

  • 체험 링크의 첫 화면을 자동으로 찍은 이미지도 함께 공개돼요.

구글 로그인을 쓸 때

  • 구글 로그인은 선택이에요. 로그인하지 않아도 결과물을 올릴 수 있어요.
  • 로그인하면 구글이 이름, 이메일 주소, 프로필 사진 정보를 내 브라우저로 보내 줘요. 이 사이트는 그중 이름만 "만든 사람" 칸에 채워 넣어요.
  • 이메일 주소와 프로필 사진은 저장하지 않고, 다른 곳으로 보내지도 않아요.

피드백을 남길 때

  • 피드백은 GitHub 계정으로 로그인한 뒤에 남길 수 있어요.
  • 남긴 피드백은 이 사이트의 GitHub 저장소에 저장되고, GitHub 아이디와 함께 누구나 볼 수 있어요.

그 밖에

  • 이 사이트는 방문 기록을 따로 모으지 않고, 광고나 방문 분석 도구를 쓰지 않아요.
  • 사이트가 올라가 있는 GitHub Pages와 글꼴을 제공하는 구글 폰트는 접속 기록을 각자의 정책에 따라 남길 수 있어요.

지우거나 고치고 싶을 때
